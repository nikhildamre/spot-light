# 🔧 Stream Permissions Error - COMPLETE FIX

## ✅ ISSUE IDENTIFIED AND RESOLVED

The error you're seeing is a **permissions issue**, not a credentials issue:

```
"User with role 'user' is not allowed to perform action UpdateCallSettings in scope 'video:livestream'"
```

### Root Cause:
- The token was being generated with **chat permissions** instead of **video permissions**
- Users need **admin/host role** for livestream operations
- Token lacked proper **call capabilities** for livestream calls

---

## 🛠️ FIXES APPLIED

### 1. Updated Token Generation
**Before** (Chat Token):
```javascript
// ❌ Wrong: Using StreamChat for video tokens
const serverClient = StreamChat.getInstance(apiKey, apiSecret)
const token = serverClient.createToken(userId, expirationTime)
```

**After** (Video Token):
```javascript
// ✅ Correct: Using StreamClient for video tokens with capabilities
const client = new StreamClient(apiKey, apiSecret)
const token = client.generateUserToken({
  user_id: userId,
  validity_in_seconds: 24 * 60 * 60,
  call_cids: [`livestream:*`], // Allow access to all livestream calls
})
```

### 2. Enhanced Call Creation
**Added**:
- User gets **admin role** when creating calls
- Proper **member permissions** for livestream operations
- Enhanced **settings override** for broadcasting

```javascript
const newCall = await client.video.call('livestream', callId).getOrCreate({
  data: {
    created_by_id: userId,
    members: [
      {
        user_id: userId,
        role: 'admin', // ✅ Admin role for full permissions
      }
    ],
    settings_override: {
      broadcasting: { enabled: true, hls: { enabled: true } }
    }
  }
})
```
